# Кері байланыс: «Не білесің? · Не білгің келеді? · Не білдің?»

Оқушылар QR кодты сканерлеп жауап жазады, жауаптары тақтада (`board.html`) бірден пайда болады.

| Файл | Не үшін |
|---|---|
| `board.html` | Мұғалімнің экраны: QR код және үш баған |
| `index.html` | Оқушы беті (QR осыны ашады) |
| `config.js` | Firebase баптаулары (толтыру керек) |
| `database.rules.json` | Базаның қорғаныс ережелері |
| `img/` | Суреттер |

---

## 1-қадам. Firebase базасын ашу (тегін, ~5 минут)

1. https://console.firebase.google.com сайтына Google аккаунтпен кіріңіз.
2. **Create a project** басыңыз. Атауы, мысалы, `keri-bailanys`. Google Analytics керек емес, оны өшіріп қойыңыз.
3. Сол жақ мәзірден **Build → Realtime Database → Create Database** таңдаңыз.
   - Location: **Belgium (europe-west1)**
   - Режимі: **Start in locked mode**
4. **Rules** қойындысын ашыңыз. Ондағы мәтінді толық өшіріп, орнына `database.rules.json` файлының ішін қойыңыз да, **Publish** басыңыз.

## 2-қадам. config.js файлын толтыру

1. Firebase-те ⚙️ **Project settings** бөліміне өтіп, төмендегі **Your apps** ішінен **`</>` (Web)** белгішесін басыңыз.
2. Кез келген атау беріп, **Register app** басыңыз. Hosting-ті белгілемеңіз.
3. Экранда `firebaseConfig = { ... }` пайда болады. Ондағы мәндерді `config.js` ішіндегі сәйкес жолдарға көшіріңіз.
   - **`databaseURL` болуы міндетті.** Егер ол көрінбесе, Realtime Database бетінің жоғарғы жағындағы `https://...firebasedatabase.app` сілтемесін көшіріп алыңыз.

> Бұл кілттер құпия емес, оларды GitHub-қа салуға болады. Базаны 1-қадамдағы ережелер қорғайды.

## 3-қадам. GitHub Pages-ке жариялау

1. https://github.com/new бетінде жаңа репозиторий ашыңыз, мысалы `keri-bailanys`. Түрі **Public** болсын.
2. **uploading an existing file** сілтемесін басып, папкадағы барлық файлдарды (`img` папкасымен бірге) сүйреп әкеліңіз де, **Commit changes** басыңыз.
3. **Settings → Pages** бөлімінде: Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** деп таңдап, **Save** басыңыз.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://<сіздің-логин>.github.io/keri-bailanys/board.html`

## Сабақта қолдану

- Проекторда **board.html** бетін ашыңыз. QR-ды басса, ол үлкейіп шығады. **⛶ Толық экран** батырмасын да қолдануға болады.
- Оқушылар QR-ды сканерлеп, сұрақты таңдайды, жауабын жазып, **Жіберу** басады.
- **🆕 Жаңа сабақ** батырмасы әр сабаққа не сыныпқа жаңа таза тақта ашады (мысалы `7А-тарих`). Бұрынғы сабақтардың жауаптары сақталып қалады. Оларға қайта оралу үшін сілтемеге `?room=атауы` қосыңыз.
- Орынсыз жауап шықса, карточканың үстіне апарып **✕** басыңыз. Карточка тек сіздің экраныңызда жасырылады.
- Жауаптарды толық өшіру үшін Firebase → Realtime Database → Data бөліміне кіріп, `rooms` ішіндегі қажетті сабақты өшіріңіз.
